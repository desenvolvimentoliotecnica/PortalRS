# UAT automatizados

Esta pasta recebe os relatórios HTML gerados pelos testes Playwright com evidências de UAT.

Cada execução cria uma subpasta com:

- `index.html`: passo a passo do fluxo executado.
- `screenshots/`: prints capturados ao final de cada etapa.

Os relatórios gerados são artefatos locais de execução e não devem ser versionados.
