# Liotecnica.Integration.RM.Logs

Pasta onde o worker **Liotecnica.Integration.RM** grava o que está rodando e o que foi extraído em cada execução.

- **extraction.log** – Registro das execuções: data/hora, extração de schema, extração de tabelas (nome da tabela, quantidade de registros ou erro).

Consulte **TABELAS_RM_IDENTIFICADAS.md** na pasta [Liotecnica.Integration.RM.Schema.Tables](../Liotecnica.Integration.RM.Schema.Tables) para o mapeamento menu/cadastros → tabelas do RM (incluindo pré-cadastro).
