Como atualizar este relatório após novos commits

  1. Abra o terminal na raiz do repositório (pasta onde está o .git).
  2. Garanta que a branch local contém os commits que deseja incluir (ex.: git pull se necessário).
  3. Execute o gerador (Python 3 e Git no PATH):
python docs/scripts/gerar_relatorio_commits.py
  1. O arquivo docs/relatorio-atividades-ultimos-15-dias.html será sobrescrito com o histórico dos últimos 15 dias relativos à data de execução.
  2. Abra o HTML no navegador para revisar ou envie ao gestor como anexo.

Fonte dos dados: git log neste repositório. O período de dias e a janela de horário estão definidos no script docs/scripts/gerar_relatorio_commits.py.
